# 🏕️ Wanderlust

Wanderlust is a full-stack web application for discovering, creating, and reviewing travel listings. Users can browse available destinations, create their own listings, upload images, add reviews, and manage their listings through an authenticated account.

## 🌐 Live Demo

🔗 [Wanderlust](https://wanderlust-lwqc.onrender.com)

## 📌 Features

- 🔐 User Authentication & Authorization
- 🏡 Create, Read, Update and Delete Listings
- 📸 Image Upload and Cloud Storage using Cloudinary
- 🗺️ Location-based listings with Mapbox
- ⭐ Add and delete reviews
- 👤 User-specific listing management
- 🔒 Protected routes and authorization middleware
- 💬 Flash messages for user feedback
- 📱 Responsive user interface
- ☁️ Deployed on Render
